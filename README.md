# Large File Splitter

Easily split files to make it easier to transfer or to read. They can be text files or binary files, we accept all types of files here!

## How does it work?

Well just compile it or download the JAR file and launch. In the split tab you can split a file. In the reconstruct tab you can reconstruct a split file.

If something does not work properly, either I'll see it and fix it, or too bad.  


## Why...

I had to repair a 10 GB video file... Guess what: opening the file in a text editor loads it all in the RAM, which is not good for really large files. I thus needed to split the file in multiple parts and reconstruct it! Why downloading an existing tool when I can create one all by myself? 

If the question is "Why in Java?", the answer is easy: because it's better than Pascal Object.
